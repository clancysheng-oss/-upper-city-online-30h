# Upper City Online — 30H

手机友好的多人 D&D 跑团网页原型，背景为“博德之门上城区”同人原创战役。

## 预计时长
完整游玩约 25–35 小时：序章 + 10 个主章节 + 终章，并预留调查、战斗、角色扮演和支线时间。

## 部署
1. 在 Supabase SQL Editor 运行 `supabase.sql`（如果你已经运行过旧版建表脚本，可以先直接测试；报重复对象时再按需要调整）。
2. 在网页首次打开时填写 Project URL 和 **anon/public** key。绝对不要使用 service_role/secret key。
3. 将整个文件夹或 ZIP 解压后的内容部署到 Vercel。
4. 玩家使用相同房间码进入，即可同步玩家列表、聊天、行动和骰子结果。

## 重要说明
这是可玩的多人战役框架，不是完整的商业级“自主 AI DM 后端”。网页中的 DM 按钮提供场景推进与主持提示；真正调用大模型需要服务器端 API，不能把模型密钥直接放在浏览器里。

序章：金门之后
1. 失踪的纹章
2. 午夜拍卖会
3. 无声钟楼
4. 三家的晚宴
5. 白鸦档案
6. 下水道王庭
7. 镜厅之夜
8. 破碎议会
9. 围城之前
10. 上城区之心
终章：黎明判决

每章按 2–3 小时设计空间，并通过调查、社交、战斗与分支选择延长至约 30 小时。
